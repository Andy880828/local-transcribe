# 否則會拉到 CPU 版 torch，無法用 GPU。
#
#   # 步驟 0：建立 Python 3.11 虛擬環境（uv 會自動下載對應 Python）
#   uv venv --python 3.11
#   #（Windows）.venv\Scripts\activate
#
#   # 步驟 1：CUDA 12.1 版 torch（RTX 4060 適用，自帶 cuDNN）
#   uv pip install torch==2.4.1 torchaudio==2.4.1 --index-url https://download.pytorch.org/whl/cu121
#
#   # 步驟 2：其餘相依（含本專案，使其可用 `transcribe` 指令）
#   uv pip install -r requirements.txt
#   uv pip install -e .
#
